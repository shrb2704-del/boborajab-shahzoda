# Онлайн-приглашение на свадьбу

Основной вариант: `invite/` — бархатный конверт с восковой печатью, вспышка света при открытии,
живая картина с лебедями, таймер, программа, место, дресс-код и анкета гостя.

Второй вариант: `invite2/` — серо-бежевый конверт с медной печатью, живая сцена с танцующей парой,
календарь с обведённой датой и программа на ниточке воздушного шарика.

Ранние черновики: `bordo/` и `shalfey/`.

Картинки, видео и музыка не хранятся в git: при публикации GitHub Actions скачивает архив
из хранилища Higgsfield и выкладывает сайт на GitHub Pages (`.github/workflows/pages.yml`).
