# Онлайн-приглашение на свадьбу

Черновые варианты сайта-приглашения (данные пока вымышленные):

- `bordo/` — бордо и слоновая кость: конверт с восковой печатью, лепестки, музыкальная шкатулка, таймлайн, анкета гостя.
- `shalfey/` — шалфей, лён и золото: открывающиеся двери, календарь с отмеченной датой, оливковые ветви, анкета с трансфером.

Сайт статический, без сборки. Для публикации можно включить GitHub Pages (Settings → Pages → ветка, папка `/`).
